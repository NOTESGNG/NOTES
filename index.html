Initialize Your Brand-New "0-File" Test Google Drive

Because your test Google Drive starts with 0 files, this complete script includes setup() (to create Year 1–5, SEM 1–10, 🕓 Pending Review, and the Config tab from scratch), plus doGet(e) and doPost(e) so this Web App talks directly to your new Drive!

Step 1: Create 1 Blank Folder

In your new test Google Drive, create one empty folder (e.g., Dept_Archive_Test) and copy its Folder ID from the URL.

Step 2: Paste Folder ID Below

Paste that Folder ID into Box 1 below and click Update Script—it injects directly into ROOT_FOLDER_ID.

Step 3: Run setup() Once

Create a blank Google Sheet in that test Drive, open Extensions → Apps Script, paste the code, and click Run → setup. This makes a separate CONFIG tab for the PIN. Already have a cluttered sheet? Run setup again (or Archive Tools → Repair Sheets) and the config rows move over automatically.

Step 4: Deploy Web App & Connect

Click Deploy → New Deployment → Web App (Execute as: Me, Access: Anyone) and paste the URL in Box 2 and click Apply to Everyone so every device connects to it!
