Setup

Connect the app to a Google Drive

Step 1: Pick a folder (optional)

Already have a notes folder? Copy its ID from the address bar. No folder yet? Skip this, and setup makes one called DEPT NOTES ARCHIVE next to your Sheet.

Step 2: Paste the folder ID

Paste it into box 1 below and click Update Script. That puts it into the code as ROOT_FOLDER_ID. Already live? Click Apply to Everyone instead to switch the connected script to that folder with no redeploy.

Step 3: Run setup() Once

Create a blank Google Sheet in that test Drive, open Extensions → Apps Script, paste the code, and click Run → setup. This makes a separate CONFIG tab for the PIN. Already have a cluttered sheet? Run setup again (or Archive Tools → Repair Sheets) and the config rows move over automatically.

Step 4: Deploy Web App & Connect

Click Deploy → New Deployment → Web App (Execute as: Me, Access: Anyone) and paste the URL in Box 2 and click Apply to Everyone so every device connects to it!

⬡ Change the lists from the Sheet, no code needed

In the Sheet's CONFIG tab, edit the Value column to add or remove choices any time: SUBJECTS (optionally CS=Computer Science), COURSES, NO_COURSE_SUBJECTS, ECO_COURSES, ECO_ONLY_COURSES. Every device picks the change up on its next sync (within about 45 seconds). Modules 1–6 and months JUL–APR are fixed in the app. Old files stay where they are, and anything outside those lists still shows under “All”.

After pasting the new code below: run setup() once (it adds the missing CONFIG rows), then Deploy → Manage deployments → pencil → New version → Deploy.
